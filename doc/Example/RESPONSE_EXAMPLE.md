# Стандартный шаблон ответа
```
{
    "status": string,
    "message": string,
    "data": array
}
```
где:
* **status** - указывает на успешное или неуспешное выполнение запроса
    * ```success``` - успешное выполнение
    * ```error``` - ошибка выполнения
* **message** - описание выполнения операции
* **data** - содержит дополнительную вспомогательную информацию
